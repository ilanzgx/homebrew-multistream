# homebrew-multistream

Homebrew tap for [Multistream](https://usemultistream.vercel.app/) — watch multiple live streams simultaneously.

## Install

```sh
brew install --cask ilanzgx/multistream/multistream
```

## Update

```sh
brew upgrade --cask multistream
```

## Uninstall

```sh
brew uninstall --cask multistream
```
